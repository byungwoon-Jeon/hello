# VS Code 활용법

Anthropic 공식 Claude Code 확장의 기능을 기준으로 작성했다. 일부 기능과 단축키는 설치 버전에 따라 달라질 수 있다.

## 파일과 코드 문맥 지정

- `@파일명` : 특정 파일 참조
- `@폴더명/` : 폴더 문맥 지정
- `@terminal:이름` : 지원하는 버전에서 터미널 출력 참조
- Windows/Linux `Alt+K` : 현재 파일·선택 영역을 참조하는 @멘션 삽입
- Windows/Linux `Ctrl+Esc` : 편집기와 Claude 패널 포커스 전환
- `Shift+Enter` : 메시지 전송 없이 줄바꿈

## 실무 프롬프트

```text
@receipt_processor.py
이 함수의 입력에서 최종 반환까지 실제 호출 경로를 추적해줘.
함수별 역할, 실패 가능한 조건, 반환 계약을 정리하고
코드는 수정하지 마.
```

```text
@src/
새 요구사항이 어디에 영향을 줄지 확인해줘.
영향받는 파일 목록과 근거, 최소 수정 방안을 제시해.
```

## 추천 권한 모드

- **Manual (default)**: 운영 코드/기존 프로젝트는 파일 변경과 주요 Bash 명령 실행을 확인
- **Plan**: 설계·분석 단계
- **자동 수정 모드**: 격리된 실험 프로젝트 등 범위가 명확할 때만

변경사항은 VS Code의 Diff UI와 Git diff로 확인한다.
선택한 파일이 아닌 다른 파일도 수정하려는 경우 범위를 다시 확인한다.

## 정확도를 높이는 지시 방식

1. 대상 파일·함수 또는 오류 로그 지정
2. 현재 증상과 기대 동작 기술
3. 지켜야 할 함수 시그니처/반환 JSON/파일명 규칙 명시
4. 코드 수정 허용 여부 명시
5. 테스트 명령과 성공 조건 명시
6. 실행 근거와 미검증 내용을 보고하도록 요청
