# 코드 영향 범위 분석

대상 요구사항/문제:

$ARGUMENTS

아래 순서로 분석한다.

1. 관련 파일, 진입점, 함수, 주요 호출자 찾기
2. 입력부터 출력·저장까지 데이터 흐름 추적
3. 외부 API, DB, 파일 I/O 및 스키마 접점 찾기
4. 변경이 필요한 코드와 그대로 유지해야 할 계약 구분
5. 회귀 가능성, 예외 케이스, 테스트 후보 제시
6. 수정 방안이 여러 개면 비용·위험·유지보수성 비교

결과 표:

| 관련 위치 | 실제 확인 내용 | 변경 필요 여부 | 위험/검증 |
|---|---|---|---|

마지막에 최소 수정 방안을 추천하되 **실제 파일은 수정하지 않는다**.
근거를 찾지 못한 부분은 추정으로 표시한다.
